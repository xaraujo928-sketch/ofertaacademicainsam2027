# Oferta académica INSAM 2027

Página web del Bachillerato Técnico Vocacional en Desarrollo de Software y Servicios Digitales del Instituto Nacional de San Martín.

Diseño y creación: Xavier Miranda.

## Abrir localmente
1. Extrae este ZIP.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. Conserva todos los archivos en la misma carpeta.

## Publicar con GitHub Pages
1. Entra a https://github.com/new y crea un repositorio público llamado `ofertaacademicainsam2027`.
2. Abre el repositorio y elige **Add file > Upload files**.
3. Sube `index.html`, `styles.css`, `app.js`, `insam.jpg` y `game-hero.png`.
4. Ve a **Settings > Pages**.
5. En Source selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
6. Guarda y espera unos minutos. GitHub mostrará la dirección de tu página.

## Publicar rápidamente sin repositorio
- Netlify Drop: https://app.netlify.com/drop
- Cloudflare Pages: https://dash.cloudflare.com/ > Workers & Pages > Create application > Pages > Drag and drop

## Editar
- `index.html`: textos y contenido.
- `styles.css`: colores, tamaños y animaciones.
- `app.js`: comportamiento interactivo.
- `game-hero.png`: ilustración de portada.
